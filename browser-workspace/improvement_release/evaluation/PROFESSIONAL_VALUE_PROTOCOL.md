# DOXA review value protocol

The product outcome is a source-backed review decision that another analyst
can verify. Measure the quality and time of that work alongside model outputs.
The current evidence includes machine timings and engineering diagnostics.
A comparative human review study and willingness-to-pay study remain pending.

## Machine workload measured now

The frozen diagnostic contains 96 original fictional passages in twelve
template families, paired across four actor substitutions. It uses the
published browser linear model implementation with its frozen local assets.
The run records 576 supported-head decisions after five warm-up passages.

On the recorded Intel Xeon Platinum 8573C Linux environment with Node.js
24.22.3, the scored batch took 279.2 ms. Median per-passage inference was
1.92 ms and the 95th percentile was 4.59 ms. Loading the local model through
its actual loader took 153.4 ms. Peak observed process resident memory was
100.2 MB. These values describe this machine, these short passages and the
linear model. Keep the full receipt and asset hashes in
`political-consistency-results.json` with the measurements.

A separate count-aggregation workload grouped 1,000 synthetic document
metadata records into forty matching cohorts in 17.6 ms. It starts from
already-computed criterion counts. File reading, PDF extraction, model
inference and reviewer activity belong to their own timing measurements.

The machine timer measures no human time saved, document-review accuracy or
buyer interest. New spend for this run was USD 0.

## Comparative reviewer study

1. Select real, permissioned document packs from a defined professional task.
   Record genre, event, topic, period, language, page count and extraction
   quality. Freeze the packs and the intended review questions before use.
2. Establish reference findings through independent reviewers, preserving
   disagreement and the exact supporting or countervailing passages. Include
   supported policy criticism, attributed quotations and careful limitations.
3. Compare the team's ordinary review process with DOXA on the same task.
   Counterbalance pack and tool order across reviewers to limit learning
   effects. Record experience, prior source familiarity and assistance used.
4. Time active reading, evidence verification, decision recording, correction
   and handoff separately. Record wall time and interruptions alongside active
   time. Capture setup and model-download time separately from repeated use.
5. Have an assessor who is blinded to the workflow judge source accuracy,
   evidence sufficiency, scope preservation and handoff usability. Record
   whether another reviewer can reproduce each decision from its case file.
6. Compare reviewer time only for outputs meeting the same quality criterion.
   Report missed findings, unsupported flags, unresolved cases, extraction
   failures and meaning-changing revisions alongside time differences.

The primary outcomes are verified source-backed decisions per active review
hour and quality-qualified completion time per document pack. Secondary
outcomes include source-location correctness, duplicated findings, reviewer
disagreement and time needed to verify the handoff. Preserve raw timing and
decision records with the review protocol and participant consent.

## Commercial evidence

Ask the intended research, editorial or institutional team which recurring
decision this review supports and what its current process costs. Use its
actual loaded hourly cost and observed review workload to estimate value.
Deduct setup, verification and integration effort from any measured benefit.
Record paid pilots, renewals and willingness to pay as separate evidence.

A USD 1,000 monthly subscription is a pricing hypothesis until actual buyers
and recurring work support it. Model benchmark improvements and a working
demo can inform a pilot discussion. A paid-product claim also needs the
service's observed reliability, document-handling arrangement and review
workflow. This release reports no measured human savings or customer demand.

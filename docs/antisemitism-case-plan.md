# Antisemitism case publication plan

## Lead with a question a reader can answer

Use Elmira Lyapina’s Global Voices report about a poster in Plzeň. Ask readers to
identify the person to whom the article attributes the religious accusation,
the group targeted by it, and the journalist’s role in reporting it. Show the
prosecution outcome as a separate reported fact. Use three contrast readings to
test the boundaries around policy debate, Holocaust analogy, and remembrance.

## Make the evidence inspectable

| Work | Acceptance check |
| --- | --- |
| Freeze the teaching set | Validate the licenses, development split, story groups, source hashes, and stored assessment records. Document purposive selection after inspection. |
| Compare the three lenses | Display all nine criterion results for the same Plzeň unit. Preserve the original indicator flag, compact outcomes, and missing explanation fields. |
| Put red flags in context | Pair each research cue with a source and a question that would strengthen or weaken a reading. Keep possible model misses separate from established facts. |
| Build the case graph | Resolve the source version, anchor, archived run, criterion, and editorial question with the existing JSON-LD vocabulary. |
| Make it readable in several formats | Offer a keyboard-friendly reader, tagged PDF, decision ledger, downloadable graph, and offline edition. Use original 8-bit illustrations based on the DOXA Quest palette. |
| Surface both studies | Feature the two studies in GitHub and local DOXA. Advertise both from the homepage section immediately after Windtunnel and from the TACITUS product page. |
| Verify the public release | Rebuild from the frozen inputs, check coverage and downloads, and exercise the live flow on desktop and narrow mobile screens. |

Independent evaluation would require reviewers to write model-blind labels under
a declared rubric before opening the saved decisions. The four selected articles
are teaching material for that process. [Evaluation protocol](methodology-v06.md)

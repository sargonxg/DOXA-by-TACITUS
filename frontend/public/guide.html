One linked workspace holds your sources, timeline, comparison matrix, observations and evidence inspector. Setup, analysis and export open in drawers. The illustrated map explains six research steps.

1Bring sources together

Open Import for PDF, DOCX, TXT, Markdown, saved HTML or ZIP. Explore the institutional case studies, or add your own material. Import metadata CSV corrects authors, institutions, dates and document types. Select a row in Sources to inspect the extraction. Successful manual imports select Corpus · all imported sources; saved analyses retain their frozen source cohorts.

Large files resume in bounded parts. After a refresh, reselect the same file to continue the original import.

Open Import →

2Declare an inquiry

Open Analyze. State your question, choose explicit frameworks, and declare the analytical reviewer role. Compare IHRA, Jerusalem and Nexus separately, examine anti-Muslim hostility, or define custom indicators, boundaries and descriptive frames.

Reviewer roles do not simulate demographic identities. Research, news/policy and teaching audiences are chosen separately when exporting.

Define an inquiry →

3Choose processing

Cloud / local shows model readiness and the monthly cap. Cloud inference is the default; each run requires explicit text-transfer consent and a budget. Local Ollama is a fallback. Optional CPU retrieval and scoring use already installed artifacts and never start a download automatically.

Processing record shows progress, costs and issues, with cancel or eligible resume. Independent model verification requires its own cloud consent and a $2 cap, preserves primary counts, and exposes raw-model differences rather than accuracy. Lexical matches support navigation, not contextual conclusions.

Check models →

4Check the evidence

Select Retained observations to open the exact highlighted passage. Interpretation separates speaker attribution, target, proposition, speaker stance, document stance and hypothetical context. Review & correct records your decision and structured v3 corrections.

Reviewed learning approves examples and freezes method candidates. Evaluation and explicit activation are required; reviews do not automatically train model weights.

Open the linked workspace →

5Compare within scope

Use the period, framework and speech-role controls, or open Filters for authors, source types, import batches and review state. Select timeline periods or author × criterion matrix cells to narrow the linked workspace. Source counts and observation counts remain separate.

Trajectory follows publication time under a frozen method; History follows assessment time. Coverage and statistical gates qualify comparisons. Absence from an incremental import does not imply deletion.

Refine the comparison →

6Export the research

Open the command-bar download button for Reports. Choose research/civil society, news/policy or teaching emphasis, then PDF, HTML, XLSX, CSV or JSONL. Reports preserve the current query snapshot, source references, method and review state.

Refresh after changes before generating a new report. A stale snapshot is rejected instead of silently changing the exported totals.

From documents
to reviewable judgments.

Follow the source, the assessment and the human decision as separate records.

1. Import and define.

Add source documents, inspect extraction and correct author, date, institution and document type. State the inquiry, select analytical criteria, choose a model and set a budget. Unreadable pages and failed ranges remain visible.

2. Read each voice in context.

Open the exact passage and surrounding source. Separate the document author from quoted speakers and hypothetical examples. Check the target, speech role and document stance before confirming, rejecting or correcting an assessment.

3. Build reviewed project memory.

Adjudicated examples can be approved for project learning. Freeze a versioned snapshot, evaluate a candidate against a baseline on held-out material, then explicitly activate it or roll back. Raw model output does not become an approved learning example automatically. This workflow does not automatically fine-tune model weights.

4. Compare the right clock.

Discourse trajectory uses source publication dates. Assessment history uses analysis and review timestamps. The same source can acquire a corrected assessment without the published discourse having changed. Keep the selected run, query scope and coverage visible.

The diagram is schematic. It does not show a measured trend or improvement.

5. Export the research record.

Choose the intended audience, then download PDF, HTML, XLSX, CSV or JSONL. The snapshot retains the selected scope, provenance, method and coverage. Human-readable reports disclose appendix limits; data formats retain the complete selection.
